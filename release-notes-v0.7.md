## What changed in 0.7.0

**Fixed:** Typing `://` (e.g. `https://`) no longer triggers the `~/` macro.
The double-tap action has been removed from the `/` key. TD(1) is now
tap=`/` · hold=MO(L7) only.

**Improved:** `~/` and `../` now live on TD(3) on the L9 middle finger.
Tap for `~/`, double-tap for `../`. Chainable — repeated double-taps
while holding the layer key build `../../` etc. without re-entering.

## Installation

Load `Cadenza-Corne-Pro_v0_7.vil` via File → Load saved layout in Vial.
OS keyboard layout must be set to **US International**.
