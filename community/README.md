# Community

This directory is the future home for community contributions to Cadenza:

- **Ports** — adaptations for other 36-key boards (Swept, Ferris, Piantor, …)
- **Language variants** — German, French, and other locale-specific layouts
- **Usage reports** — real-world feedback on tipping terms and layer usage

See [CONTRIBUTING.md](../CONTRIBUTING.md) for how to submit a port or variant.
