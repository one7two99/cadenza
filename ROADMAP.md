# Cadenza Roadmap

## v0.7 — Layer completions

- [ ] **L10 System / Workspace** — window management, virtual desktop switching, screenshot, lock screen. Access: G hold (index finger, left hand)
- [ ] **Tune L9 in practice** — adjust after real-world usage; the four current macros may be reordered by frequency

## v1.0 — Stability

- [ ] **Caps Word** — double-tap Shift HRM to activate; auto-deactivates after Space
- [ ] **Per-layer encoder maps** — extend beyond L0–L3 (currently KC_TRNS in L4–L9)
- [ ] **Tipping term refinement** — community data on optimal per-finger timing

## v1.1 — Language variants

- [ ] **German variant** — Umlauts via dead-key macros (pattern already established by M2–M4); ä ö ü ß placement
- [ ] **ISO vs ANSI** — document differences for non-US system layouts

## v1.2 — Ports

- [ ] **Native QMK `keymap.c`** — removes Vial dependency, allows >16 macros, enables features unavailable in Vial (Achordion, Caps Word, combos)
- [ ] **ZMK port** — wireless Corne builds (nice!nano)
- [ ] **Other 36-key boards** — Swept, Ferris, Piantor

## v2.0 — Community edition

- [ ] **Web configurator** — generate personalised `.vil` without editing JSON
- [ ] **Cadenza Lite** — no Tap Dance HRM; plain modifiers for beginners
