Why Cadenza over QWERTY?

Problem with QWERTYCadenza solution
High same-finger bigrams (ed, ce…)Colemak-DH distributes load evenly across all fingers
Common letters on weak fingersAll 5 most-frequent English letters (E T A O I) on home row
Lateral stretch for B, Y, HColemak-DH moves these inward — minimal lateral movement

Design Principles

  1. Home position first — every frequent key reachable without wrist movement
  2. Symmetric layer access — L7, L8, and L9 reachable from either hand
  3. Unified numpad grid — same physical shape for symbols (L4), numbers (L5), F-keys (L6)
  4. Finger-tuned timing — tipping terms match natural speed per finger
  5. Tap = primary, Hold = secondary — consistent paradigm throughout
  6. Macros earn their slot — only sequences with genuinely mixed shifted characters qualify
  7. Vial-native configuration — all settings editable without a firmware rebuild

Key Design Decisions

Design decision — Vial-first constraint

Cadenza is deliberately designed to stay within the 16 macro slots available in standard Vial firmware. Increasing this limit requires recompiling QMK from source and flashing custom firmware, after which the .vil file is only fully portable to keyboards running that exact custom build. Staying within 16 macros means the layout can always be loaded, edited, and restored using the standard Vial desktop app — no build toolchain required. This constraint directly shaped the Code & CLI layer: only sequences with genuine multi-key complexity earn a slot; repeated-character sequences like || and && do not.

Design decision — Layer access: middle finger down vs index finger sideways

The Code & CLI layer (L9) is triggered by holding C (left) or , (right) — the middle finger moving down one row. The alternative was using G or M (index finger stretching laterally to the inner column). The middle finger was chosen because vertical movement along a finger's natural axis is shorter, more comfortable, and does not destabilize the hand the way a lateral index stretch does. The index finger anchors the hand's lateral position; moving it inward shifts the entire hand. G and M therefore retain their existing assignment (tap = letter, hold = App/Menu) unchanged.

L0 Base Layer (Colemak-DH) ESC / SPC / TAB hold (left) · ENT / BSP / DEL hold (right)

L9 Code & CLI Hold C or Hold ,

Four focused macros on the right home row — the highest-value multi-character sequences for coding and shell work. Left hand stays free for modifiers.

Single characters like ||, &&, :: are intentionally not macros — they are just the same key pressed twice, which is already fast. Only sequences with genuinely different shifted characters earn a macro slot.

Cadenza uses 10 of 16 available Vial macro slots (M0–M9). Six slots remain free. The 16-slot limit is a deliberate constraint — staying within standard Vial firmware means no custom build is required to load or edit the layout.
